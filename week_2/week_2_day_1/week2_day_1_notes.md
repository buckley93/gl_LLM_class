## Closed Source LLMs (Proprietery) vs open source

# time to market
- Proprietary models are easy to deploy and dont need to take care of infrastructure
- Open source models requires time and expertise to set up self hosting

# Cost to structure
- Proprietary useage_based
- open source models are distributed freely

# Latency
- Proprietary Longer response time
- open source models on use cases, models can be smaller, and therefore, faster

# Flexibility and transparency
- proprietary no visibility into the code
- open source offers the most transparency and flexibility

# Security and governance
- proprietary offers added security and governance capabilities
- open source lacks security and governance capabilities
